Dashboard de Vendas Xbox Game Pass

Descrição do Projeto

Este projeto foi desenvolvido como parte do desafio proposto pela DIO, com o objetivo de criar um Dashboard de Vendas no Excel capaz de transformar dados brutos em informações estratégicas por meio de indicadores visuais e análises interativas.
A solução permite acompanhar o desempenho das assinaturas Xbox Game Pass, fornecendo métricas relevantes para análise de vendas, comportamento dos assinantes e geração de receita.

Objetivo
Desenvolver um dashboard interativo para consolidar e visualizar informações relacionadas às assinaturas do Xbox Game Pass, facilitando a análise dos dados e apoiando a tomada de decisões baseada em indicadores de desempenho.

Funcionalidades Implementadas:
Indicadores (KPIs)

O dashboard apresenta os seguintes indicadores estratégicos:

- Valor total das vendas realizadas.
- Ticket médio das assinaturas.
- Quantidade total de assinantes.
- Receita gerada pelo EA Play Season Pass.
- Receita gerada pelo Minecraft Season Pass.
  
Análises Visuais
- Comparação da receita entre assinaturas com renovação automática ativa e inativa.
- Distribuição dos assinantes por tipo de plano.
- Análise consolidada dos valores gerados pelos serviços adicionais.

Interatividade
- Segmentação de dados para filtragem por tipo de assinatura.
- Atualização dinâmica dos indicadores e gráficos conforme os filtros selecionados.
- Navegação simplificada para exploração dos dados.

Ferramentas e Recursos Utilizados

Para o desenvolvimento do projeto foram utilizados recursos nativos do Microsoft Excel, incluindo:
- Tabelas Dinâmicas;
- Gráficos Dinâmicos;
- Segmentação de Dados (Slicers);
- Consolidação de métricas através de tabelas auxiliares;
- Cálculo de KPIs para acompanhamento de desempenho;
- Organização e tratamento da base de dados;
- Formatação e design de dashboard para melhor visualização das informações.

Estrutura da Base de Dados

A análise foi realizada a partir de informações relacionadas às assinaturas Xbox Game Pass, contendo dados como:
- Identificação do assinante;
- Plano contratado;
- Tipo de assinatura;
- Data de início da assinatura;
- Renovação automática;
- Valor da assinatura;
- EA Play Season Pass;
- Minecraft Season Pass;
- Valor de cupons aplicados;
- Valor total da compra.


Resultado

O dashboard desenvolvido permite analisar rapidamente o desempenho das vendas por meio de indicadores-chave, fornecendo uma visão consolidada sobre faturamento, ticket médio, quantidade de assinantes e receitas provenientes dos serviços adicionais do ecossistema Xbox Game Pass.
